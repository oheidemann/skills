# Parking Lot

Ideas kept for later. An idea here can be fully clear, even fully designed — what
keeps it here rather than in flight is that it isn't validated yet, or that
building it now would interfere with the current work stream. Clarity isn't the
bar; sequencing and unproven assumptions are.

Distinct from *deliberately out of scope*: a decision that something is ruled
out entirely, a boundary rather than a waiting room. Also distinct from an open
question actively blocking real work — that belongs to a planning or grilling
session, not here. This is for ideas nobody is currently pushing on.

**A parking-lot item never influences current or future design.** If an idea
here is already shaping a real decision — a field left nullable because of it,
a config kept empty for it — that's the signal it doesn't belong here anymore.
Pull it out and make it a proper, citable decision (an ADR, a comment at the
place it shapes) instead of leaving it parked but load-bearing. Parked and
influential are never the same file at the same time.

One file per idea, not one growing document — easier to link to, and easier to
see what's actually here at a glance. Named for the concept, not for who raised
it.
